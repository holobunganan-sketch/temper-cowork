# REASONIX_PARITY.md — Reasonix 功能 Parity 追踪

> PHASE C 填充。每项能力记录:Upstream owner / Upstream test / Upstream desktop surface / Temper surface / Adapter / Automated test / Manual smoke / Status。

## 状态枚举

- UPSTREAM_AVAILABLE — upstream 存在,尚未在 Temper 接线
- TEMPER_WIRED — Temper 已接线
- ADVANCED_ONLY — 仅 Advanced 页面可用
- CLI_ONLY — 仅 CLI
- NOT_WIRED — 未接线
- OUT_OF_SCOPE_WITH_REASON — 明确排除
